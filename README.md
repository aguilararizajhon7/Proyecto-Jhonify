# Jhonify 

Quiero una aplicación web con las opciones de cambiar de tema claro a tema oscuro negro total sobre música con el logo jhonify y quiero que se pueda buscar canciones y reproducir, también quiero las siguientes pantallas perfil, biblioteca, favoritos y en el principio quiero iniciar sesión con correo o número y contraseña y una pantalla de registro de usuario cada botón debe ir con un color azul
